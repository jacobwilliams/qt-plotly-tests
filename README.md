
### Requirements

Required dependencies:

Name      | Version
---       | ---
numpy     |     2.5.2     
pandas    |     3.0.5     
plotly    |     6.9.0     
pyside6   |     6.11.1    
python    |     3.14.7    
qt6-webengine |  6.11.1   

These can be installed using [pixi](https://pixi.prefix.dev/latest/) by typing `pixi shell`.

### Tests

* `test_browser.py` : Open a browser in an embedded pyside6 window.
* `test_map.py` : draw a simple map and open it in an embedded pyside6 window.
